## Match the power supply

Your Raspberry Pi will need to be powered. 

> [!TASK]
>
> Think about how you will power your cyberdeck. Use the recommended values below.

| Model | Voltage | Recommended current |
|---|:---:|:---:|
| Raspberry Pi 1 (all models) | 5 V | 2.5 A |
| Raspberry Pi 2 Model B | 5 V | 2.5 A |
| Raspberry Pi 3 (all models) | 5 V | 2.5 A |
| Raspberry Pi Zero (all models) | 5 V | 2.5 A |
| Raspberry Pi 4 Model B | 5 V | 3 A |
| Raspberry Pi 5 | 5 V | 5 A |
| Raspberry Pi 400 | 5 V | 3 A |
| Raspberry Pi 500 | 5 V | 5 A |
| Raspberry Pi 500+ | 5 V | 5 A |

> [!TIP]
>
> - If you are unsure, use the official power supply for the Raspberry Pi model.
> - Plugging into mains power means any model will work. You will need to check which power supply it needs.
> - A Raspberry Pi Zero is best if you want it to be battery powered or use a portable power bank.
